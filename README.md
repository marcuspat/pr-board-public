# pr-board-public

Sanitized public mirror of the PR-board snapshot, pushed by the VPS every 30 min (crontab 7,37).

Private-repo PRs appear as stubs (repo + number + bucket only — no titles, no notes). Raw URL:

`https://raw.githubusercontent.com/marcuspat/pr-board-public/main/pr-board.json`
